\# CareerPredict AI



\## Student Placement Prediction System Using Machine Learning



\### Project Description



CareerPredict AI is a Machine Learning-based web application that predicts the most suitable placement company for a student based on academic performance and technical skills.



The application is developed using Python, Flask, Pandas, Scikit-learn, HTML, and CSS.



\---



\## Features



\- Student Placement Prediction

\- User-Friendly Web Interface

\- Machine Learning Model

\- Fast Prediction

\- Easy to Use

\## Installation



Install the required libraries:



pip install -r requirements.txt



Train the model:



py train\_model.py



Run the application:



py app.py



Open:



http://127.0.0.1:5000
